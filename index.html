Type-C 內錄阻值量測

麥克風 未連線 訊號 停止

步驟

1. 將 Type-C 耳機插入 Pixel 9a，確認回灌迴路已接好（耳機輸出 → 3296W → 麥克風）。
2. 把媒體音量調到 80%～100% 並在整個測試中保持不變。
3. 點「連接麥克風」並允許權限。

輸入裝置

授權後會自動選擇 label 含 USB / Wired / Headset 的裝置；若系統只顯示「default」，Android 通常已自動路由到耳機麥克風。

訊號源

輸出為 0 dBFS 滿刻度正弦波，代表手機能送出的最大訊號。實際語音只會更小，所以在此校準到 RMS ≈ 0.4 對語音是安全的。

阻值預測

RMS – 阻值 曲線

頻率響應（250 Hz – 8 kHz）

依序播放 250 / 500 / 1k / 2k / 4k / 8k Hz，各取樣 0.5 秒，畫出相對 1 kHz 的響應。日文 さ・し・つ・は 行子音能量集中在 4–8 kHz，若 8 kHz 衰減超過 −6 dB，建議調低阻值。

測試語音

尚未載入
預設三句由網路載入（若該主機未開放 CORS 會載入失敗，請改用「自選檔案」先把檔案下載到手機再選取）。載入過的音訊會存於本機，離線可用。

播放並比對

程式從 Type-C 播放測試語音，同時錄下回灌訊號，對齊後計算原音與回錄的差異。
判讀：SDR ≥ 20 dB 極佳、12–20 dB 可用、< 12 dB 有明顯失真或高頻缺失。4–8 kHz 頻帶差越接近 0 dB 越好。回錄峰值應 < −3 dBFS 且削波 0 次。
