# Type-C 耳機純內錄改裝：最佳阻值量測 PWA

在 Pixel 9a / Chrome 上執行的 PWA。透過 Web Audio API 由 Type-C 輸出測試訊號，
再擷取經 3296W 可變電阻回灌到耳機麥克風的無損波形，協助找出最佳阻值。

## 功能
1. **裝置**：授權後自動選擇 USB / Wired / Headset 輸入，關閉 AEC / NS / AGC 並顯示實際生效值，即時波形、RMS、峰值、THD。
2. **1kHz 校準**：0 dBFS 正弦波，多幀平均取樣；削波（峰值 ≥ 0.95）或 THD > 5% 標記無效；以跨越 RMS 0.4 的兩點線性內插預測目標阻值。
3. **頻響**：250 Hz – 8 kHz 六點掃描，相對 1 kHz 繪圖，用於檢查高頻（日文子音區）衰減。
4. **語音比對**：播放日文測試句並同步錄下回灌訊號，互相關對齊、增益補償後計算 SDR 與各頻帶差。
5. 所有結果依阻值綁定存於 localStorage，可匯出 CSV。

## 部署
需 HTTPS（`getUserMedia` 限制）。將整個資料夾放到 GitHub Pages 或任何靜態空間即可，於 Chrome 開啟後可「加到主畫面」安裝。

## 使用注意
- 測試全程請將媒體音量固定在 80%–100%，不要變動。
- 預設三句測試語音由網路載入並存於 IndexedDB；若載入失敗（CORS），請先下載音檔再以「自選檔案」載入。
